# RigShade — public site

The public information site for **RigShade**, an Android USB OTG editor and preset notebook for the
M-VAVE Cube Baby electric guitar pedal.

| Page | What it is |
|---|---|
| `index.html` | the product page: what RigShade is, what it works with, and captures of the app |
| `privacy/index.html` | the privacy policy — the page Google Play links to |
| `support/index.html` | getting started, the tuner, presets, and answers to common questions |

Questions, problems and ideas: **padillameng@users.noreply.github.com**

## Published address

The site is served by GitHub Pages at <https://padillameng.github.io/Rigshade-Site/>, and the policy
page at <https://padillameng.github.io/Rigshade-Site/privacy/>. Pages has to be switched on once in
the project settings, with the site published from the top folder.

## Before changing anything visual

Read [MASTER_SITE_CONTEXT.md](./MASTER_SITE_CONTEXT.md) first. It holds the approved identity, the
layout rules, the compatibility wording and the mistakes not to repeat.

## What is in here

| Path | Contents |
|---|---|
| `css/styles.css` | the product page's stylesheet |
| `css/pages.css` | the rules the document pages add on top |
| `js/main.js` | the mobile menu |
| `assets/brand/` | the logo and the favicon |
| `assets/screenshots/` | real captures of the app, as it looks on a phone |

## What this site does not do

It asks the browser for nothing else: no third-party fonts, scripts, images or analytics. Every
file a visitor needs is in this folder.
